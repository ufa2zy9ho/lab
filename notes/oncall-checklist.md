# On-Call Checklist

Quick reference for handling incidents while on call.

## First 5 Minutes

1. Acknowledge the page.
2. Assess severity and impact.
3. Open a dedicated incident channel.
4. Assign roles: lead, comms, scribe.
5. Start a running timeline.

## During the Incident

- Keep the timeline updated with actions and observations.
- Communicate status to stakeholders every 30 min.
- Focus on mitigation, not root cause.
- Escalate early if unsure.
- Record all commands run and outputs.

## Before Declaring Resolved

- Confirm service health from the user perspective.
- Check monitoring dashboards and logs.
- Note any follow-up actions.
- Announce resolution and next steps.

## Post-Incident

- Schedule a blameless review within 3 days.
- Update runbooks and dashboards.
- Track action items to completion.
